# `api.constants`

```ts
api.constants.physics.normal          // 0 — default sim
api.constants.physics.skip            // 1
api.constants.physics.aggressiveSkip  // 2
```

Used with `api.elements.setPhysicsAtCell(cx, cy, state)`.

Engine cell size and related numbers: `api.config.getLegacy()` / `api.gameConfig` / `api.rendering.getGridMetrics()`.
