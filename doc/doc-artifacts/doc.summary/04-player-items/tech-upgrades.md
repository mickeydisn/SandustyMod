# Tech & upgrades

```js
api.tech.registerDefinition("myMod.tech1", {
  nameKey: "mods|myMod|tech1|name",
  cost: 100,
});
api.tech.conservatory.appendUnlock(sandkit.enums.Tech.SignalDevices, {
  structures: ["myMod.sensor"],
});
```
